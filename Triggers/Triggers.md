# Triggers

## Markdown Table Generator

`table-generator.yml` is an Espanso trigger that uses `mdtable` as a trigger for an form that lets you specify a number of rows and columns, along with headings, then generates a table in markdown.

## HTML Elements

`html.yml` is a collection of triggers that correspond to HTML elements. It contains most of them, and you can add or remove whatever ones you don't need or that conflict with other triggers you use.

## Custom Color Names

`espanso-mycolor.zip` is a download you should save in your match folder and extract there. Once you've done that, run the `setup-windows.bat` file to make sure you have everything installed that you need. After that, you should be able to use the `mycolor` trigger for adding hex code triggers.
